## 一、三個階梯（這部分查得到）

### 四大／顧問 [已驗證]

`Analyst／Associate → Consultant → Senior Consultant → Manager → Senior Manager → Director → Partner`

每級約 2–3 年，Analyst 到 Partner 約 12–17 年。
來源：[Deloitte 路徑](https://www.hackingthecaseinterview.com/pages/deloitte-consulting-career-path)、[KPMG 六級制](https://managementconsulted.com/kpmg-careers/)、[Big 4 綜覽](https://www.roadtooffer.com/blog/consulting-career-path)。台灣本地薪資階梯（Staff 起薪約 NT$34,000／In-charge 約 NT$42,000–52,000）見 [Dcard 四大薪資討論](https://www.dcard.tw/f/job/p/235908073)、[四大升遷制度整理](https://notes.shhjusttellyou.com/promotion/)。

### 台灣企業端 [已驗證]

`助理 → 專員 → 資深／高級專員 → 副理 → 經理 → 協理 → 處長`

`專員` 是基層到中階的執行職，位置在督導職之下。
來源：[職稱階級對照](https://prepedu.com/zh-hant/blog/company-position-titles-english)、[50 個中英職稱對照](https://ieltstongxue.com/company-job-hierarchy-chart-in-english/)、[Taiwan Office Hierarchy 討論](https://tw.forumosa.com/t/taiwan-office-hierarchy/224665)。

### 新加坡 [已驗證]

`Executive → Senior Executive → Assistant Manager → Manager → Senior Manager → AVP → VP → Director`

**這一格最容易害人**：新加坡的 `Executive` 是**基層**，多數情境下等同 assistant 級。台灣人直覺會把 Executive 讀成「主管」，那個誤讀會直接害你談錯薪水、或把一個平移的機會當成降級而放棄。
來源：[Singapore 職級說明](https://sg.indeed.com/career-advice/finding-a-job/what-is-an-executive)、[entry-level 職稱指南](https://employers.digitalgrads.com/2021/06/24/entry-level-job-titles-guide/)、[新加坡企業層級](https://hierarchystructure.com/singapore-business-hierarchy/)。永續／ESG 實際職稱與薪資帶見 [eFinancialCareers](https://www.efinancialcareers.com/news/2023/07/esg-jobs-singapore)（SGD 65k–400k）、[Michael Page SG](https://www.michaelpage.com.sg/jobs/sustainability/singapore)。

## 三、你四個判斷的 brutal review

### ① 「四大兩年≈資深專員；3–5 年≈副理；6–7 年爭取經理」

**部分站得住，但它是最好情況不是通則。**

四大兩年在四大內部是 Staff／Consultant；台灣的資深專員一般對應 3–6 年在職經驗。所以「四大兩年 → 資深專員」隱含了一個約兩年的**四大溢價**。那個溢價在重視四大的公司（金控、上市櫃永續部門、外商）是真的，在不重視的公司（多數傳統製造業）會直接消失——同樣兩年只給專員。

**建議寫法**：把它標成「在重視四大資歷的公司」，不要寫成通則。

### ② 「Senior Consultant 五年 = 中間主管如副理；我面試玉山拿到經理」

**這是最需要修正的一條，而修正點是你自己已經講出來的。**

你在同一句話裡給了兩個 confound：**你離職時是 Manager，不是 Senior Consultant**，而且**你唸完了 MBA**。所以那個玉山「經理」offer 是「Manager ＋ MBA → 經理」的證據，**不是「Senior Consultant 五年 → 經理」的證據**。

這個差別對讀者很要緊：一個 Senior Consultant、沒有 MBA 的人，如果照這張表去期待經理，他會錨在一個拿不到的職級上，然後在談判桌上輸掉。

另外一件查不到、但值得標記的事：台灣金融業的「經理」很多時候是**職等**而不是帶人的主管職。[Dcard 民營銀行職等對照圖](https://www.dcard.tw/f/financial/p/239074534) 存在但擋爬取（HTTP 403），[比薪水玉山頁](https://salary.tw/c/Nyt3) 只有專員級數字（月薪約 NT$39,000–50,000），查不到職等與帶人的對應。**這一格是 [查不到]。**

### ③ 「永續經理 → Manager」

**站得住。** 但失效方向跟你想的相反：危險不在你把自己的職級估低，而在**讀者把新加坡的 Executive 讀成主管**。一個台灣永續經理看到 JD 寫 Senior Executive，可能誤判成降級而不投——實際上薪資帶可能相同或更高。

### ④ 「金融端收啊，我拿很多 offer，靠碳、產業經驗、利害關係人議和、法規」

**機制上站得住，而且有外部證據支持你講的那條路。**

Bank of America 的 Global Head of Sustainable Finance 明講，銀行最大的挑戰是 Scope 3，因為它涵蓋整條價值鏈；銀行正在建的是投融資組合的碳強度追蹤（[S&P Global](https://www.spglobal.com/sustainable1/en/insights/how-financial-institutions-are-tackling-portfolio-emissions)、[BofA 訪談](https://spglobal.com/esg/podcasts/why-bank-of-america-says-scope-3-emissions-biggest-challenge-for-banks)）。**一個真的替半導體廠算過排放的人，知道那個分母的問題長什麼樣；銀行的組合團隊在猜。** 你講的「產業經驗對應到投資組合的範疇三」在結構上就是這件事。

**但你的樣本是一個人，而且有 confound**：INSEAD MBA ＋ 新加坡碳市場現職。你拿到的 offer 有多少能歸因於那四項可轉移能力、有多少歸因於學校與現職，無法從一個樣本分辨。

**我查不到的**：沒有 MBA 的四大 ESG 顧問，拿到金融端 offer 的比例。WSO 與 Reddit 上找到的是需求端機制（[WSO 銀行永續金融組討論](https://www.wallstreetoasis.com/forum/investment-banking/banks-with-sustainable-financerenewable-energy-groups)、[WSO Climate Finance](https://www.wallstreetoasis.com/resources/skills/esg/climate-finance)），不是錄取率。所以這一條對外只能寫成「這條路存在且有機制支撐」，**不能寫成「顧問轉金融很容易」**。

## 四、四維判斷框架（你指正的「不只是 title」）

同一個 title 在不同軌道差很多，所以讀者要問的是四個問題，不是查一張表。

| 維度 | 要問的那一句 | 為什麼它會騙人 |
|---|---|---|
| **薪水** | 這個數字是 base，還是含獎金／分紅？年度總包是多少？ | 顧問的 base 通常較高、變動較少；企業端的年終與分紅可以佔總包兩三成，只比 base 會誤判 |
| **帶不帶人** | 我會有幾個直屬下屬？他們的考績由誰打？ | 顧問的 Manager 帶專案團隊但多半不是正式直屬；企業端的經理可能帶 0 人。**考績權**是唯一分得清的問法 |
| **未來出路** | 做完這一任，下一步通常是誰？他們現在在哪裡？ | 有些位置（純法遵、純報告書撰寫）進去就很難出來。問前任去了哪裡，比問職涯路徑圖有用 |
| **決策權** | 我有沒有預算？多少額度以內我自己拍板？ | 這是「資深執行者」與「主管」的真正分界，而 title 兩邊都可能叫經理 |

**降級陷阱**：顧問 Manager → 企業端資深專員，四個維度可能三升一降（薪水升、出路升、決策權升、帶人降）。那不是降級。反過來，title 升到經理但沒有預算、沒有考績權、前任是被調走的——那是降級穿著升遷的衣服。
