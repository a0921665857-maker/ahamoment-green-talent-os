# 四條職涯階梯的換算：從四大到企業端，從台北到新加坡

> 對外閱讀版 v1 · 2026-07-30
> 作法：把公開資料聚合起來，對上一個真實個案，交叉詰問之後留下站得住的部分。每一格標把握程度，沒有把握的照實說。

---

## 你真正想問的那一題

你在四大做了幾年，想知道跳到企業端算什麼位置；或者你在台灣掛經理，想知道到新加坡是什麼 title、值多少錢。這一題沒有標準答案，但它有一個可以查的部分和一個不能查的部分，而多數人卡在把兩者混在一起。

**可以查的**：四條軌道各自的階梯，包括每一級大概幾年、對應的英文職稱。這部分有公開紀錄，下面直接給你。

**不能查的**：階梯之間的換算。四大三年等於企業端哪一級，公開紀錄只停在「業界慣例」這個等級，沒有任何一方把它寫成規則。任何一張把它寫成規則的表，都超譯了它手上的資料。

所以這一份的重點放在第三件事：既然 title 不可換算，換算什麼才有用。答案在最後一節。

### 把握程度怎麼讀

| 標記 | 意思 |
|---|---|
| **有公開紀錄** | 兩個以上互相獨立的來源說法一致 |
| **單一來源** | 只有一處這樣寫，還沒有第二個聲音 |
| **業界慣例** | 很多人這樣講，但沒有任何一方寫成明文 |
| **公開紀錄未建立** | 這件事目前沒有被寫下來。不是沒發生，是沒有紀錄可以引用 |

## 一、四條階梯本身

### 四大與顧問 · 有公開紀錄

```
Analyst  →  Consultant  →  Senior Consultant  →  Manager  →  Senior Manager  →  Director  →  Partner
0–2 年       2–4 年          4–6 年               6–9 年      9–12 年            12–15 年     15 年以上
```

每一級大約 2 到 3 年，從 Analyst 走到 Partner 約 12 到 17 年。台灣本地的起薪帶：Staff 約 NT$34,000，In-charge 約 NT$42,000 到 52,000。

來源：[Deloitte 職涯路徑](https://www.hackingthecaseinterview.com/pages/deloitte-consulting-career-path)、[KPMG 六級制](https://managementconsulted.com/kpmg-careers/)、[四大綜覽](https://www.roadtooffer.com/blog/consulting-career-path)、[Dcard 四大薪資討論](https://www.dcard.tw/f/job/p/235908073)、[四大升遷制度整理](https://notes.shhjusttellyou.com/promotion/)。

### 台灣企業端 · 有公開紀錄

```
助理  →  專員  →  資深專員  →  副理  →  經理  →  協理  →  處長
```

「專員」在這條階梯上是執行職，位置在督導職之下。這一點值得記住，因為它是下面第二個陷阱的起點。

來源：[職稱階級對照](https://prepedu.com/zh-hant/blog/company-position-titles-english)、[中英職稱對照 50 例](https://ieltstongxue.com/company-job-hierarchy-chart-in-english/)、[Taiwan Office Hierarchy 討論](https://tw.forumosa.com/t/taiwan-office-hierarchy/224665)。

### 新加坡 · 有公開紀錄

```
Executive  →  Senior Executive  →  Assistant Manager  →  Manager  →  Senior Manager  →  AVP / VP  →  Director
（基層）      （基層資深）
```

來源：[Executive 職級說明](https://sg.indeed.com/career-advice/finding-a-job/what-is-an-executive)、[entry-level 職稱指南](https://employers.digitalgrads.com/2021/06/24/entry-level-job-titles-guide/)、[新加坡企業層級](https://hierarchystructure.com/singapore-business-hierarchy/)。永續與 ESG 的實際職稱與薪資帶見 [eFinancialCareers](https://www.efinancialcareers.com/news/2023/07/esg-jobs-singapore)（SGD 65,000 到 400,000）、[Michael Page SG](https://www.michaelpage.com.sg/jobs/sustainability/singapore)。

## 二、對照表：慣例等級，不是規則

| 年資 | 四大／顧問 | 台灣企業端 | 金融／基金 | 新加坡 | 揭薪錨點（月薪） |
|---|---|---|---|---|---|
| 0–3 年 | Analyst → Consultant | 專員 → 資深專員 | Analyst | Executive → Senior Executive | 顧問 SGD 3,750–4,250（中位數 4,125，n=8）<br>企業端 SGD 3,750–4,200（中位數 4,000，n=8） |
| 4–8 年 | Senior Consultant → Manager | 資深專員 → 副理 → 經理 | Associate／AVP | Assistant Manager／Manager | 企業端 SGD 5,000–6,750（中位數 5,750，n=7） |
| 8 年以上 | Senior Manager → Director | 經理 → 協理 | VP／Executive Director | Senior Manager／VP／Director | 樣本累積中（顧問 n=3、企業端 n=2） |

**中間四欄的把握程度：業界慣例。** 個別公司的差異大到足以推翻一整列，所以請把它當成起點，不是結論。

**揭薪錨點怎麼來的**：每週日自動掃亞太綠領職缺，把明確揭薪的那些收進帳本，同一格滿 5 筆才公布，公布的是中位數與 P25 到 P75。目前夠格公布的只有三格，都在新加坡，因為新加坡的官方職缺平台強制揭薪，台灣與香港沒有這個規定。這是資料來源的現實，不是編輯選擇。

## 三、三個會讓你虧錢的誤讀

這一節比對照表有用，因為換算錯了通常不是差一級，是虧錢或者錯過一個本來該投的機會。

### 誤讀一：把新加坡的 Executive 讀成主管

台灣人看到 Executive 的直覺是「執行長那一系」，但在新加坡它是基層職，很多情境下等同 assistant 級。

**代價往兩個方向走。** 一個台灣的永續經理看到 JD 寫 Senior Executive，可能判斷成降級而不投，實際上薪資帶可能相同甚至更高。反過來，看到 Executive 就以為自己升了一階去談薪，會談在一個明顯偏低的位置上。

### 誤讀二：把台灣金融業的「經理」當成帶人的主管職

台灣金融業有不少「經理」是職等，不是管理職。同一個字在製造業和金融業指的可能是完全不同的東西。

這一格的把握程度是**公開紀錄未建立**。Dcard 上有民營銀行的職等對照圖，但頁面擋外部讀取；比薪水的玉山頁面只有專員級的數字（月薪約 NT$39,000 到 50,000），沒有職等與帶人的對應關係。也就是說，這件事在圈內是常識，但沒有一份公開文件把它寫下來，所以這裡只能提醒你去問，不能給你一張表。

**要問的那一句**：這個位置有幾個直屬下屬，他們的考績由誰打。

### 誤讀三：把「四大溢價」當成到處都算

「四大兩年抵企業端三到四年」這件事是真的，但它只在重視四大資歷的公司成立：金控、上市櫃的永續部門、外商。在不重視的公司，同樣兩年就是兩年，只給專員。

所以這個溢價要當成一個**條件式**的東西：它是你在某些公司可以主張的籌碼，不是你在所有公司都帶著的資產。談之前先判斷對面屬於哪一種。

## 四、我自己的個案，以及為什麼它不能當通則

這一節放我自己的資料，因為它剛好示範了個案為什麼危險。

我從四大出來的時候是 Manager，面試玉山拿到的是經理。表面上看，這是一個「顧問轉金融端，職級平移甚至微升」的乾淨案例。

但這個案例有兩個混在一起的因素：**我離職時的職級是 Manager**，而且**我當時已經唸完 MBA**。所以它能證明的是「Manager 加 MBA 換到經理」，證明不了「Senior Consultant 五年換到經理」。

差別在哪裡：一個 Senior Consultant、還沒有 MBA 的人，如果照著我的個案去期待經理，他會把自己錨在一個拿不到的職級上，然後在談判桌上輸掉一輪。同一個 offer，換一個人身上就不成立。

我拿到過幾個金融端的 offer，靠的是四項可轉移能力：淨零與碳的實作、產業經驗（管理半導體與科技業的排放，對應到金融端投資組合的範疇三）、利害關係人議和與溝通、法規理解。

**這條路在機制上站得住。** Bank of America 的永續金融全球主管公開講過，銀行最大的挑戰就是範疇三，因為它涵蓋整條價值鏈；銀行現在建的正是投融資組合的碳強度追蹤（[S&P Global](https://www.spglobal.com/sustainable1/en/insights/how-financial-institutions-are-tackling-portfolio-emissions)、[BofA 訪談](https://spglobal.com/esg/podcasts/why-bank-of-america-says-scope-3-emissions-biggest-challenge-for-banks)）。一個真的替半導體廠算過排放的人，知道那個分母的問題長什麼樣；銀行的組合團隊還在猜。

**但我不會把它寫成「顧問轉金融很容易」。** 我的樣本是一個人，而且帶著 INSEAD 和新加坡碳市場現職這兩個因素。「沒有 MBA 的四大 ESG 顧問，拿到金融端 offer 的比例是多少」這個數字，公開紀錄未建立。找得到的是需求端的機制（[WSO 銀行永續金融組討論](https://www.wallstreetoasis.com/forum/investment-banking/banks-with-sustainable-financerenewable-energy-groups)、[WSO Climate Finance](https://www.wallstreetoasis.com/resources/skills/esg/climate-finance)），不是錄取率。

所以這條路的正確讀法：**它存在，而且有結構性的需求支撐它。至於你走不走得通，取決於你能不能把那四項能力拿出證據。**

## 五、可以換算的四個維度

回到開頭那一題。title 在四條軌道之間不可換算，因為它只是各家內部的記帳單位。能換算的是這四個維度，而且它們都可以在面試裡直接問出口。

| 維度 | 直接問這一句 | 它為什麼會騙人 |
|---|---|---|
| **薪水** | 這個數字是 base，還是含獎金與分紅？年度總包多少？ | 顧問的 base 通常較高、變動較少；企業端的年終與分紅可以佔總包兩三成。只比 base 會判斷錯。 |
| **帶不帶人** | 我會有幾個直屬下屬？他們的考績由誰打？ | 顧問的 Manager 帶專案團隊，多半不是正式直屬；企業端的經理可能帶 0 人。考績權是唯一問得清楚的切法。 |
| **未來出路** | 做完這一任，下一步通常是誰？前一位現在在哪裡？ | 有些位置（純法遵、純報告書撰寫）進去之後很難出來。問前一位去了哪裡，比看職涯路徑圖有用。 |
| **決策權** | 我有沒有預算？多少額度以內我自己拍板？ | 這是「資深執行者」與「主管」的真正分界，而兩邊的 title 都可能叫經理。 |

### 用這四個維度重算一次「降級」

顧問 Manager 轉企業端資深專員，看 title 是降級。看四個維度可能是三升一降：薪水升、出路升、決策權升，只有帶人降。那不算降級。

反過來，title 升到經理，但沒有預算、沒有考績權、前一位是被調走的。那是降級穿著升遷的衣服。

**這就是為什麼這一份沒有把中間四欄寫成規則。** 那四欄能給你的最多是一個起點，真正決定這一步值不值得的，是上面四句話問出來的答案。
